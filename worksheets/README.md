# DSE 中五「網上威脅及保安」工作紙

對應教育局《資訊及通訊科技課程及評估指引》必修單元「互聯網及其應用 — 網上威脅及保安」。

## 檔案

| 檔案 | 說明 |
|------|------|
| `DSE_中五_網絡保安_工作紙_學生版.docx` | 學生工作紙（50 分／約 40 分鐘） |
| `DSE_中五_網絡保安_工作紙_答案.docx` | 教師參考／評分建議 |
| `create-network-security-worksheets.js` | 以 docx 技能重新產生文件的腳本 |

## 試卷結構

1. **甲部** 多項選擇題（10 分）
2. **乙部** 填充及配對（10 分）
3. **丙部** 短答題（15 分）
4. **丁部** 情境結構題（15 分）
5. 溫習清單與應試小貼士

涵蓋：病毒／蠕蟲／木馬／間諜軟件／勒索軟件、未經授權存取、攔截、動態網頁入侵、DoS、防毒、防火牆、認證與授權、WPA、VPN、釣魚與私隱等。

## 重新產生

```bash
cd worksheets
npm install docx   # 若尚未安裝
node create-network-security-worksheets.js
```
